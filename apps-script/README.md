# 구글 시트 동기화 설정 (Google Apps Script)

스케줄 보드의 데이터를 구글 시트에 저장하고 여러 사람과 공유하기 위한 설정입니다.
**한 번만** 설정하면 됩니다.

## 1. Apps Script 열기
1. 공유하려는 구글 시트를 엽니다.
2. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭.

## 2. 코드 붙여넣기
1. 기본으로 보이는 `Code.gs`(또는 `코드.gs`) 내용을 모두 지웁니다.
2. 이 폴더의 [`Code.gs`](./Code.gs) 내용을 전부 복사해 붙여넣고 **저장**(💾)합니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** 클릭.
2. 톱니바퀴(유형 선택) → **웹 앱** 선택.
3. 설정:
   - **설명**: 아무거나 (예: 스케줄보드 API)
   - **실행 계정**: `나`
   - **액세스 권한이 있는 사용자**: **`모든 사용자`**
4. **배포** 클릭 → 권한 승인(본인 구글 계정으로 허용).
5. 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/..../exec`)을 복사합니다.

## 4. 보드에 연결
1. 스케줄 보드 사이트에서 상단 **`🔗 공유`** 버튼 클릭.
2. 복사한 **웹 앱 URL**을 붙여넣고 확인.
   - 시트가 비어 있으면 → 현재 보드 데이터가 시트로 업로드됩니다.
   - 시트에 데이터가 있으면 → 시트 데이터를 불러옵니다.
3. 함께 쓰는 사람도 같은 사이트에서 같은 URL을 넣으면 동일한 데이터를 봅니다.

## 동작 방식 / 참고
- 보드에서 추가·수정·삭제하면 자동으로 시트에 반영됩니다(시트의 **`스케줄보드`** 탭).
- 다른 사람이 바꾼 내용을 보려면 상단 **`↻ 불러오기`** 를 누르세요(또는 페이지 새로고침).
- 저장 방식은 **마지막 저장이 우선(last-write-wins)** 입니다. 같은 항목을 동시에 편집하면
  나중에 저장한 쪽으로 덮어쓰여질 수 있으니, 동시 편집은 피하는 것을 권장합니다.
- URL을 아는 사람은 데이터를 읽고 쓸 수 있으니 URL 공유 범위에 유의하세요.
- 코드를 수정한 경우 **배포 → 배포 관리 → 편집 → 새 버전**으로 다시 배포해야 반영됩니다.
